# SmartPlayFPL — Public Release

Open models and dataset behind **[SmartPlay](https://smartplayfpl.com)**, a free AI-powered Fantasy Premier League analytics platform.

## The Website

[smartplayfpl.com](https://smartplayfpl.com) gives FPL managers two things:

1. **Expected points (xPts)** — a predicted score for every Premier League player every gameweek, generated by a multi-bucket mixture of position-specific XGBoost regressors trained on 251 features from the FPL and Understat APIs.
2. **Squad optimiser** — enter your FPL team ID and get mathematically optimal transfers, captain picks, and lineup decisions via a mixed-integer linear program powered by [HiGHS](https://highs.dev).

The site also includes fixture difficulty ratings, side-by-side player comparisons, and multi-gameweek chip planning (Wildcard, Free Hit, Bench Boost, Triple Captain). Everything is free, with no account required.

For full technical details on the prediction pipeline, solver, and accuracy benchmarks, see [How It Works](https://smartplayfpl.com/under-the-hood). For our transparency principles and strict no-gambling policy, see [Ethics](https://smartplayfpl.com/ethics).

## This Repository

This repo is a self-contained, public-friendly release of the prediction models and training dataset that power the site.

- Start here: `models/README.md`
- Git LFS required (for `data/smartplay_data.csv`)
- License: CC BY-NC 4.0 (see `LICENSE`)
- Includes:
  - `models/openfpl_model/` — OpenFPL inference wrapper (downloads upstream models on first run)
  - `models/smartplay_model/` — SmartPlay v9 pre-trained XGBoost weights + runner
  - `data/smartplay_data.csv` — training/evaluation dataset (Git LFS)
